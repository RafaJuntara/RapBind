# RapBind 0.3.DL - minimal command test

This version only tests native `/bind` registration.

1. Build with GitHub Actions.
2. Put `RapBind.asi` beside `gta_sa.exe`.
3. Start SA-MP 0.3.DL.
4. After SA-MP loads, a small confirmation box should appear saying the command was registered.
5. Close it and type `/bind`.
6. A second box should appear.

No UI, config, keybinds, or extra hooks are included yet.
